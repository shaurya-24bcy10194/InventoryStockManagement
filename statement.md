# Project Statement

## Project Title

Inventory & Stock Management System

## Problem Statement

Managing product inventory manually can lead to incorrect stock records,
difficulty in tracking stock movement, and delays in identifying products
that need restocking.

The Inventory & Stock Management System is designed to provide a simple
console-based solution for maintaining product information and monitoring
stock levels.

## Proposed Solution

The system allows an administrator to manage products, monitor available
stock, record stock-in and stock-out transactions, search products, identify
low-stock items, and generate inventory reports.

The application uses Java and object-oriented programming concepts.
Product and transaction information is stored using text files so that
important data can remain available after the application is closed.

## Main Features

- Administrator login
- Add new products
- View product inventory
- Search products
- Update product information
- Delete products
- Add stock
- Remove stock
- Record stock transactions
- Detect low-stock products
- Generate inventory reports
- Generate transaction reports
- Generate category reports
- File-based data storage
- Input validation
- Exception handling
