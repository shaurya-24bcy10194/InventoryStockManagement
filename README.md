# Inventory & Stock Management System

## Project Overview

The Inventory & Stock Management System is a Java-based console
application designed to simplify product and inventory management.

The system allows an administrator to manage products, monitor stock
levels, record stock-in and stock-out transactions, search products,
identify low-stock items, and generate inventory reports.

The project demonstrates important Java Object-Oriented Programming
concepts along with file-based data storage.

---

## Objectives

The main objectives of this project are:

- Manage product information efficiently
- Track available inventory
- Record stock-in and stock-out operations
- Identify products with low stock
- Search products by name or category
- Generate inventory and transaction reports
- Store data using text files
- Demonstrate Java OOP concepts
